# Browse forecasts

Choose a sport, competition, season or tournament year, then the **forecast month**. Months refer to the date the forecast was made, as recorded in the filename, not the event date. Each original JSON stays next to its matching `.json.ots` proof.

This archive contains **409 JSON files and 409 OTS files**. F1, policy predictions, and pilot runs are excluded.
