# Browse forecasts

Choose a **sport → competition → season or tournament year**. Each season or year folder contains its forecast JSON files and matching `.json.ots` proofs directly. Original filenames record the forecast and target dates.

This archive contains **409 JSON files and 409 OTS files**. F1, policy predictions, and pilot runs are excluded.
